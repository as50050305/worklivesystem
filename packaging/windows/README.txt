工作生活規劃（Windows 版）
==========================

全部資料都存在你的電腦，不需要註冊任何帳號。需要 Windows 10 或 11（64 位元）。

【第一次安裝】
1. 把這個 zip「解壓縮」到你想放的位置（例如 D:\工作生活規劃）。
   ※ 不要直接在 zip 裡面雙擊，要先解壓縮。
2. 雙擊 install.bat。
   如果出現「Windows 已保護您的電腦」：按「其他資訊」→「仍要執行」。
3. 安裝完成後，桌面會出現「工作生活規劃」捷徑。

【每天使用】
雙擊桌面的「工作生活規劃」，瀏覽器會自動打開 http://localhost:5858/
使用期間工作列會有一個最小化的黑色視窗，關掉它就是結束程式。

【更新】
雙擊 update.bat，會從 GitHub 下載最新版。你的資料（data 資料夾）不會受影響。
第一次更新時，如果 GitHub 專案是私有的，會請你貼上一組唯讀權杖（畫面上有步驟）。

【備份】
- 每天第一次開啟時，會自動備份整個資料庫到 data\snapshots（保留 14 天）。
- 每次更新資料庫結構前，也會先備份一份（檔名有「升級前」）。
- 但這些都在同一台電腦。請定期在 App 的「設定 → 匯出／匯入」下載備份，
  存到隨身碟或雲端硬碟。

【搬到新電腦】
在新電腦安裝後，用 App 的「設定 → 匯出／匯入」匯入備份檔；
或關掉程式後，把整個 data 資料夾複製到新電腦的同一位置。

【從自動快照還原】
1. 關掉程式的黑色視窗。
2. 在這個資料夾的空白處按右鍵 →「在終端機中開啟」，輸入：
   .local\node\node.exe local\server.mjs --restore-snapshot data\snapshots\檔名.tar.gz
   （目前的資料會先移到 data\pgdata-還原前-… 保留）
